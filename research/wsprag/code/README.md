# WSP-RAG experiment source

The files here make the experimental code browsable on GitHub. Download the [complete reproducibility archive](../../../assets/research/wsprag/reproducibility.zip) for frozen data, settings, raw responses, results, and independent replay scripts. Read its README before running anything. The target networks are tiny synthetic classifiers, not language models.
